# Kerala Lottery AI

Features:
- Telegram Bot
- Lottery Result Fetcher
- Prediction Generator
- Flask Website
- JSON Storage

## Run Website

```bash
pip install -r requirements.txt
python web/app.py
```

## Run Telegram Bot

1. Create bot using BotFather
2. Replace YOUR_BOT_TOKEN in bot/bot.py

```bash
python bot/bot.py
```
